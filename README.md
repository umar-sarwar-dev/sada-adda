# Sada Adda 🍵

A landing page concept for **Sada Adda** — a fictional chai & qehwa spot in Lahore. Built as a design + front-end practice project, styled around desi chai culture rather than a generic template.

## 📖 About

Sada Adda ("our spot," in Punjabi) is a small cafe brand concept. The page tells its story, shows the menu, and gives visiting hours — built to feel like a real neighborhood cafe, not a stock template.

## 🛠️ Built With

- **HTML5** — semantic structure
- **CSS3** — custom properties, responsive grid layout, keyframe animation
- **JavaScript** — scroll-reveal animation, mobile nav toggle

## ✨ Features

- Custom color palette (charcoal, saffron, clay) inspired by chai & clay cups
- Animated steam rising from a CSS-drawn cup in the hero section
- Menu styled like a chalkboard, with categorized items and prices
- Hours displayed as a punch-ticket style card
- Fully responsive with a mobile nav drawer
- Scroll-triggered reveal animations, with `prefers-reduced-motion` respected

## 🚀 Getting Started
